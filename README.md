# Controle de Compras com Cartão de Crédito

Projeto desenvolvido em Java durante meus estudos na Alura, com o objetivo de praticar conceitos de Programação Orientada a Objetos e coleções.

## 📌 Sobre o projeto

A aplicação simula um sistema de controle de compras com cartão de crédito. O usuário informa o limite do cartão e pode registrar compras, consultar o saldo disponível e finalizar a operação para visualizar as compras realizadas.

## ⚙️ Funcionalidades

- Informar o limite inicial do cartão.
- Consultar o saldo disponível.
- Registrar compras com descrição e valor.
- Verificar se existe saldo suficiente antes de aprovar uma compra.
- Atualizar o saldo após cada compra aprovada.
- Listar as compras realizadas em ordem crescente de valor.

## 💻 Tecnologias e conceitos utilizados

- Java
- Programação Orientada a Objetos (POO)
- Classes, atributos e construtores
- Encapsulamento e métodos getters
- `ArrayList` para armazenar as compras
- `Scanner` para entrada de dados
- Estruturas condicionais e laços de repetição
- `Comparator` para ordenar as compras
